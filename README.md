<h1 align="center">FiRasel Terminal Portfolio</h1>

A Terminal Styled Portfolio Website with sound effects.

## Technologies

- [Next.js 15](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [TypeScript 5](https://www.typescriptlang.org/)
- [TailwindCSS 4](https://tailwindcss.com/)
- [Howler.JS](https://howlerjs.com/)

## Run Locally

Clone the repository

```bash
git clone https://github.com/firasel/Terminal-Portfolio.git
```

Go to the project directory

```bash
cd Terminal-Portfolio
```

Install dependencies

```bash
yarn install
```

Start the server

```bash
yarn dev
```

Build for production

```bash
yarn build
```

## Project Structure

```
src/
├── app/                  # Next.js 15 App Router
│   ├── layout.tsx       # Root layout with metadata
│   └── page.tsx         # Home page
├── components/
│   ├── Home/            # Main container
│   ├── SoundControl/    # Volume control
│   ├── Terminal/        # Terminal emulator + templates
│   └── TextDrop/        # Keypress animation
└── styles/
    └── globals.css      # TailwindCSS v4 config
```
